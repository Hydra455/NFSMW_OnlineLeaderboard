# NFSMW_OnlineLeaderboard

This mod adds an online leaderboard to Need for Speed Most Wanted main menu, using the game own UI. Compare records across Sprint, Circuit, Drag, Lap Knockout, Tollbooth and Speedtrap events, with player names, cars and personal bests shown for each race. Times update automatically when you beat your record, while Speedtrap ranks by total speed. This mod is experimental so expect bugs to happen until heavy tested by other players

Also this mod works for now only for the world races, is not working for quick races or challenge series
