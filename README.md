# NFSMW_OnlineLeaderboard

This mod adds an online leaderboard to Need for Speed Most Wanted main menu, using the game own UI. Compare records across Sprint, Circuit, Drag, Lap Knockout, Tollbooth and Speedtrap events, with player names, cars and personal bests shown for each race. Times update automatically when you beat your record, while Speedtrap ranks by total speed. This mod is experimental so expect bugs to happen until heavy tested/fixed by other players
